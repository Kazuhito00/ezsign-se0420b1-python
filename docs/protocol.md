# SE0420B1 USB protocol notes

SE0420B1の4色USBモデルについて、参考実装・公式配布アプリとの照合と実機確認で整理したメモです。
公開されたメーカー公式SDKの仕様書ではありません。

## Transport and frames

- シリアル: 115200 bps、8N1、フロー制御なし。
- 画像: 400×300、2bpp、30000バイト、行順、1バイトに4画素を上位ビット側から格納。
- 色: 黒=0、白=1、黄=2、赤=3。
- 1ページ: 16バイト×1875ブロック。ブロック番号は0〜1874。

```text
BB type command length content checksum 7E
```

`length` はcontentのバイト数（1バイト）。`type` は送信00、受信01。
チェックサムはtypeからcontent末尾までの総和の下位8ビットです。
画像データ自身にBBや7Eが含まれるため、応答は終端探索ではなく長さで区切ります。

## Commands

| 操作 | 送信command | content | 応答content |
|---|---|---|---|
| 機種識別 | `0A` | `07` | 先頭が製品ID `42`。実機の受信commandは例外的に `01` |
| スロット照会 | `01` | page | `01` または `FE`（既存画像あり） |
| 転送先選択 | `03` | page, `00` | 成功=`01` |
| ブロック書き込み | `04` | 番号上位, 番号下位, 16バイト | 成功=`01` |
| ブロック読み取り | `05` | page, `00`, 番号上位, 番号下位 | 番号上位, 番号下位, 16バイト |
| ページ表示 | `00` | page | 指定page |

pageは1〜5。ページ表示には次=`FE`、前=`FF`も指定できます。
3色向け参考実装とフレーム・チェックサム・16バイト転送の考え方は共通ですが、
3色向けの38400 bps・2プレーン方式は使いません。

機種識別の実機フレーム:

```text
TX BB 00 0A 01 07 12 7E
RX BB 01 01 01 42 45 7E
```

書き込みはスロット照会 → 転送先選択 → 1875ブロック送信 → ページ表示要求の順です。
電源OFFでもOS側にシリアルポートが見える場合がありますが、本体の応答とは別です。
再送・電源ON・自動OFF設定変更のコマンドは実装していません。
